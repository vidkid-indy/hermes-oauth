Privacy Policy — Hermes Agent

Last updated: 26 October 2026

Hermes Agent ("the application") is a private, self-hosted assistant operated by a single individual ("the operator"). This policy explains what Google user data the application accesses, why, and how it is handled.

1. Google user data accessed

  • Gmail (gmail.readonly, gmail.modify, gmail.send) — reading message headers and bodies to summarise what needs attention, and sending messages the operator explicitly requests.
  • Google Calendar (calendar) — reading events from the operator's calendars to prepare a daily briefing and to create or delete events on request.
  • Google Drive (drive) — searching, uploading and downloading files on request.
  • Google Sheets and Docs (spreadsheets, documents) — reading and writing content on request.
  • Google Contacts (contacts.readonly) — resolving names to email addresses.

All access happens through OAuth 2.0 tokens issued by Google to the operator's own account. The application has no other route to the operator's data.

2. How the data is used

Data is used only to perform the tasks the operator asks for — for example, composing a morning briefing from calendar events and recent email. Data is never used for advertising, profiling, credit assessment, or training general-purpose models.

3. Storage

  • OAuth access and refresh tokens are stored in a configuration file on the operator's own self-hosted server, readable only by the application's service account.
  • Email and calendar content is processed in memory and summarised on demand. Message bodies are not retained in a database; only short operational logs (timestamps, task names, error text) are kept.
  • No Google user data is stored on third-party servers operated by the application author.

4. Sharing with third parties

The application does not sell, rent, or transfer Google user data to third parties. To generate summaries, excerpts of the content being summarised may be sent to the AI model provider configured by the operator (a language-model API) solely for that request. No other party receives the data, and no advertising or analytics services are used.

5. Limited Use disclosure

Hermes Agent's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. Retention and deletion

  • Tokens persist until the operator revokes access or deletes them.
  • Access can be revoked at any time at myaccount.google.com/permissions. Revoking access immediately stops all further data access.
  • To request deletion of any stored token or log, email the address below; the data is deleted within 30 days.

7. Security

The application runs on a private server behind an authenticated network layer. Tokens are stored with filesystem permissions restricted to the service account, and transport to Google uses TLS.

8. Children

The application is not directed to children under 13 and does not knowingly process their data.

9. Changes

Material changes to this policy will be published on this page with an updated date.
