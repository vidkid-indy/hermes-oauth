Hermes Agent

A personal, self-hosted AI assistant — single-user application

Hermes Agent is a private automation assistant operated by one individual for their own use. It connects to the operator's own Google account with explicit OAuth consent in order to produce a daily calendar and email briefing, and to send messages the operator writes.

What it does with Google data

  • Google Calendar — reads events across the operator's calendars to build a morning briefing.
  • Gmail — reads recent messages to flag anything urgent, and sends email only when the operator explicitly asks it to.
  • Google Drive, Sheets, Docs, Contacts — accessed only on direct request from the operator.

Who can use it

The application is not offered to the public. There is no sign-up, no multi-tenant hosting, and no third-party end users. The only person whose data is accessed is the operator who granted access.
